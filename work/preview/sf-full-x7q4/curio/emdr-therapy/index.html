Curiosity no. 07 · EMDR therapy

What is EMDR, really?

EMDR therapy in Denver

EMDR is a way to work through a disturbing memory so it stops running the present. You don’t have to describe the memory in detail for it to work.

How it works

EMDR stands for Eye Movement Desensitization and Reprocessing. Francine Shapiro developed it in the late 1980s, and it has been studied closely as a treatment for PTSD ever since.

In a session you hold a memory in mind while following a back-and-forth stimulus: eye movements, taps, or tones. That seems to help the brain file the memory the way it files ordinary ones. People often say the memory is still there afterward and no longer carries the same charge.

The memory stays. The alarm goes quiet.

What it can help with

  • Flashbacks, nightmares, and intrusive thoughts
  • Panic and phobias
  • Grief that hasn’t moved
  • Body sensations tied to an old event
  • Beliefs like “it was my fault” that you know aren’t true and still feel true

Questions people ask

Do I have to talk about what happened?

Not in detail. You need to be able to bring the memory to mind. You don’t need to narrate it.

Is there homework?

No. The processing happens in session.

Does it work over video?

It can. Sarah teaches a course for therapists on adapting EMDR to telehealth.

How many sessions will it take?

It depends on what you’re bringing. A single recent event can move quickly. A long history takes longer, and the preparation matters more.
