How this site is built

  • 01
    Typed, not generatedEvery page is plain HTML, one stylesheet and a little JavaScript, written by hand. No framework, no page builder, no build step. View source and it reads the way it was typed.
  • 02
    The television is realEach channel on the homepage is the live site, loaded in a frame at desktop width and scaled down to fit the screen. Phones get a still of each site instead, because a scaled frame of a whole website crashed Safari on an iPhone more than once.
  • 03
    The static is drawnThe snow between channels is random noise painted onto a small canvas every frame, with a rolling band so it looks like a set from before you were born. Changing pages gets the same blink.
  • 04
    The paper is realThe receipt, the ticket stubs and the index card in the journal are scans of actual paper. The receipt and stubs stretch with border-image, so their torn ends keep their shape at any width, and the words on them are still real text you can select, and the print button prints only the receipt, centered, with nothing else on the page.
  • 05
    Fonts live hereCormorant Garamond, DM Serif Display and Jost are self-hosted as woff2 files, so nothing is fetched from a font service and the text shows up in one paint.
  • 06
    The footer knows what time it isThe sign-off changes by the hour in Denver, and the “last changed” date reads the file’s own modified date, so nobody has to remember to update it.
  • 07
    Hosted for nothingThe site is a folder in a Git repository, served by GitHub Pages. No server, no database, no monthly bill, which is the same deal every client gets.
  • 08
    Other things to tryThe old up-up-down-down code surfs every channel. The Scan button does the same, politely. The barcode at the bottom of the receipt is real Code 128, so point a scanner at it. There’s a calculator on the colophon; you know what to type. Holding the dial is how you got here.
